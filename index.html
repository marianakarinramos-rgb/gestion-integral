Manual de Operaciones

Guía rápida para la gestión diaria del sistema.

Punto de Venta y Cobros

  • Vender: Ingresá al Punto de Venta, seleccioná el cliente, el vendedor y buscá los productos. Al "Añadir", armás el carrito. Clic en "Enviar a Caja" para generar el Presupuesto.
  • Cobrar Presupuesto: Desde la pestaña "Presupuestos", el Cajero hace clic en "Cobrar". Selecciona el método de pago y el sistema descuenta el stock e imprime el Remito.
  • Contraentrega: Si cobrás en domicilio, elegí "Contraentrega". El remito dirá "A COBRAR EN DOMICILIO". Cuando el fletero vuelve con la plata, vas a "Remitos / Entregas" y le das a RENDIR CAJA.

Listas de Precios y Costos (B2B)

  • Lógica de Precios: El sistema nunca te pide que tipeés el precio de venta a mano (salvo que quieras poner un Precio Fijo). Vos cargás el Costo Base del producto.
  • Las Listas: En la solapa "Listas de Costos", creás listas con porcentajes (Ej: Minorista 50%, Mayorista 20%). El sistema multiplica automáticamente el costo base por ese porcentaje para darte el precio final.
  • Inflación: Si tu proveedor aumenta los costos, vas a "Importar Excel" en la solapa de Costos, subís la lista nueva, y todos los precios (Minoristas, Web y Mayoristas) se recalculan solos.

Sueldos y Comisiones

  • Directorio: Dás de alta a un vendedor, le asignás un Sueldo Base y un % de comisión. El sistema le crea automáticamente un PIN de acceso (Si el rol es "Vendedor", al ingresar solo verá el Punto de Venta).
  • Liquidación Mágica: A fin de mes, vas a la solapa "RRHH y Sueldos". El sistema suma todas las ventas que hizo esa persona en la caja diaria, calcula la comisión, le suma el sueldo base y descuenta las faltas.
  • Recibos PDF: En la misma pantalla, elegís al empleado, apretás un botón y te genera un Recibo de Sueldo formal en PDF listo para firmar.

Notas de Crédito y Anulaciones

  • Emitir N.C.: En "Remitos / Entregas", buscá el remito del cliente que devuelve la mercadería y seleccioná "Nota Crédito". Elegí si fue por arrepentimiento (vuelve al stock) o por rotura (no vuelve al stock).
  • Impacto Contable: Al emitir la N.C., el sistema generará automáticamente un "Gasto" (Egreso) en la Caja Diaria para reflejar que le devolviste el dinero al cliente.
  • Documento Oficial: El remito original pasará a estado "Anulado" y aparecerá un botón rojo para imprimir la Nota de Crédito oficial en PDF con los items devueltos.

Rentabilidad Neta y Financiera

  • Gastos Fijos: Cargá alquiler, luz, sueldos fijos en el tablero de Rentabilidad (Abajo a la derecha). El sistema permite clonarlos de un mes a otro.
  • Rentabilidad Real: El sistema cruza lo vendido vs el Costo Directo (CMV), los Gastos Variables (Tarjetas/Comisiones) y los Gastos Fijos para decirte cuánto ganaste de forma limpia. Las ventas web se separan del local para su análisis.
  • Simulador de Objetivos: Te dice exactamente cuántos pesos tenés que vender en el mes para cubrir tus costos fijos y llevarte la ganancia libre que vos pongas como objetivo.
